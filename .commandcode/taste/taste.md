# Taste

## UI / Layout
- Wants content cards to span the full width of the screen rather than being constrained to a narrow column (`max-w-3xl`-style containers); long content should wrap instead of overflowing. Confidence: 0.75
- Expects one consistent visual style across every UI page and role — create/edit/delete forms, dashboard, lists, profile, and auth — matching the already-approved admin style; when restyling one page, extend it everywhere rather than leaving pages in mixed styles. Confidence: 0.7
